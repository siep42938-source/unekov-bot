# 🚀 Как запустить Unekov.help бота

## Шаг 1 — Создай бота в Telegram

1. Открой Telegram, найди **@BotFather**
2. Напиши `/newbot`
3. Введи имя: `Unekov Help`
4. Введи username: `unekovhelp_bot` (или любой свободный, должен заканчиваться на `bot`)
5. **Скопируй токен** — он выглядит так: `1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ`

---

## Шаг 2 — Узнай свой Telegram ID

1. Напиши боту **@userinfobot**
2. Он ответит твоим ID, например: `123456789`

---

## Шаг 3 — Установи PostgreSQL

### Вариант A: Docker (рекомендуется, проще всего)

Установи [Docker Desktop](https://www.docker.com/products/docker-desktop/) и запусти:

```
cd osint-ai-bot
docker-compose -f docker-compose.dev.yml up -d
```

PostgreSQL будет доступен на `localhost:5432`

### Вариант B: Локальная установка

Скачай и установи [PostgreSQL](https://www.postgresql.org/download/windows/)
- При установке задай пароль: `password`
- Создай базу данных `osintbot`

---

## Шаг 4 — Настрой .env файл

```
cd osint-ai-bot
copy .env.example .env
notepad .env
```

Заполни обязательные поля:

```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ   ← токен от BotFather
ADMIN_IDS=123456789                                  ← твой Telegram ID
SECRET_KEY=любая-строка-минимум-32-символа-здесь    ← придумай сам
OPENAI_API_KEY=sk-...                                ← если есть (опционально)
```

DATABASE_URL оставь как есть если используешь Docker:
```env
DATABASE_URL=postgresql+asyncpg://postgres:password@localhost:5432/osintbot
```

---

## Шаг 5 — Установи Python зависимости

```
cd osint-ai-bot
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

---

## Шаг 6 — Запусти бота

```
python main.py
```

Или двойной клик на `setup.bat` — он сделает всё автоматически.

Ты увидишь:
```
✅ Database initialized
✅ Default data seeded
🤖 Bot: @unekovhelp_bot
✅ Ready! Press Ctrl+C to stop.
```

**Открой Telegram → найди своего бота → напиши /start**

---

## Шаг 7 — Индексация файлов (опционально)

Чтобы бот искал по твоим файлам из `bif BD/`, `Telegram Users/` и т.д.:

```
python scripts/index_files.py
```

Или через бота командой `/admin_index` (только для admin).

---

## ❓ Частые проблемы

**`ModuleNotFoundError`** — не активировано venv:
```
venv\Scripts\activate
```

**`connection refused` (PostgreSQL)** — БД не запущена:
```
docker-compose -f docker-compose.dev.yml up -d
```

**`Unauthorized` (Telegram)** — неверный BOT_TOKEN в .env

**Бот не отвечает** — проверь логи в `logs/bot.log`

| Команда | Описание |
|---------|----------|
| `/start` | Запустить бота |
| `/menu` | Главное меню |
| `/admin_index` | Индексировать файлы (admin) |
| `/admin_stats` | Статистика (admin) |
| `/admin_grant <id> <amount>` | Выдать токены (admin) |
